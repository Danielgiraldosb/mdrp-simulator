# Manuscript: Fair dispatching with price-responsive couriers (EJOR)

This folder is the Overleaf project. It is also a `git subtree` of the main repository
`Danielgiraldosb/mdrp-simulator` (path `docs/paper-cmdp/paper/`), published as the standalone
repository `dalvarezmartinez/mdrp-paper` so that Overleaf's GitHub Sync can import it.

Files: `main.tex` (manuscript), `references.bib`, `elsarticle-harv.bst` (author-year style, as in the
authors' previous EJOR papers), `figures/` (F1, F2 generated by `simulator/figures_paper.py`;
F3-F8 come from the X1-X3 experiments), `estilo-ejor.md` (style guide extracted from the previous
manuscripts), `main_v0.tex` (first draft, kept for reference), `main.pdf` (last local build).

Compile: pdfLaTeX + BibTeX (elsarticle-harv), or `tectonic main.tex`. Do not put `\todo{}` inside
`\author`, `\ead` or `\title`: elsarticle writes them to the .aux and the colour macro breaks there.

## Sync workflow

Edit in Overleaf, then use the Overleaf menu GitHub -> "Push Overleaf changes to GitHub". In the main
repository the changes are pulled with

    git subtree pull --prefix=docs/paper-cmdp/paper paper main --squash

and pushed back (after local edits, e.g. results filled from `simulator/output/paper/`) with

    git subtree push --prefix=docs/paper-cmdp/paper paper main

followed by GitHub -> "Pull GitHub changes into Overleaf" in the Overleaf menu. `paper` is the git
remote `https://github.com/dalvarezmartinez/mdrp-paper.git`.
